# Impactful Tom 1.0.0

Impactful Tom is an independent, unofficial founder-performance Augment for one live business decision. It helps expose the governing constraint, separate mission from attachment to a tactic, and choose an evidence-calibrated move with an owner, threshold, review horizon, and stop-or-continue interpretation.

This release includes:

- a Codex repository-marketplace plugin;
- a standalone skill archive;
- a portable Claude Code/generic skill archive; and
- one complete customer kit containing both host forms and the reader documentation.

The founder method was exercised across 24 canonical TestForge cases: 20 were demonstrated, four retained one bounded partial criterion, and none failed or became invalid. The final instruction body and behavior-bearing resources are byte-identical to that exercised method. Two catalog descriptions changed to the current Augment format, so final routing and first success are verified separately through the public installation route.

Impactful Tom is not Tom Bilyeu and is not affiliated with, endorsed by, sponsored by, or authorized by Tom Bilyeu, Impact Theory, or their companies. The release excludes raw transcripts, private prompts, Thoughtcore, the source headshot, copied playbook blocks, likeness, quotation, and affiliation claims.

See `README.md` for first use, `docs/installing-and-maintaining.md` for installation and removal, `docs/provenance-and-verification.md` for the evidence boundary, and `release/assets/v1.0.0/SHA256SUMS.txt` for archive hashes.
