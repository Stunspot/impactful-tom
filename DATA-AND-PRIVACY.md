# Impactful Tom Data and Privacy

Impactful Tom 1.0.0 is distributed as a local Codex repository plugin and a portable Claude Code/generic skill directory. The package includes no account, telemetry, analytics, hosted service, connector, MCP server, hook, or automatic network request. Collaborative Dynamics does not receive founder records, prompts, business data, or generated outputs through Impactful Tom itself.

Data entered while using Impactful Tom is handled by the AI host, model provider, operating system, repository host, and any tools the user chooses to invoke. Their terms, privacy controls, retention rules, and network behavior govern that processing. Users remain responsible for deciding whether those surfaces are appropriate for confidential company, employee, customer, investor, financial, security, or trade-secret information.

Conversation is session-only by default. Impactful Tom creates a portable `founder-case.md` only when the user explicitly asks for continuity and chooses the location. That file remains wherever the user or host places it. The package does not upload, synchronize, enrich, delete, or transmit it by itself.

Users should be able to inspect, correct, export, and delete a Founder Case. If the host cannot write to the chosen location, the honest result is a portable draft marked **not saved**, not an implied durable record.

This statement describes the public 1.0.0 package as built. Any future connector, hosted service, telemetry, analytics, or tool-backed edition requires a new privacy review and an updated statement before release.
